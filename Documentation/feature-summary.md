# Feature Summary

## Dashboard

Shows:

- total projects
- active projects
- completed projects
- delayed projects
- overall progress
- upcoming milestones
- status distribution
- risk-oriented project cards

## Calendar

Shows:

- a month grid
- filter chips
- search field
- project distribution by week

## Projects

Shows:

- project cards
- create project form
- status, priority, health, and progress on each card

## Project Detail

Shows:

- project header
- owner/manager/tech lead summary
- timeline section
- WBS table
- progress updates
- task create/edit form
- dependency display

## Gantt

Shows:

- timeline bars per project
- date header
- today marker concept

## Kanban

Shows:

- projects grouped by status
- progress and health cues

## Planner

Shows:

- hourly schedule slots
- inbox tasks
- planning-oriented layout

## Reports

Shows:

- compact project reporting table
- manager
- schedule window
- progress
- health
