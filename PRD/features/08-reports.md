# Reports

Route: `/reports`

## Tujuan

Tabel ringkas seluruh project, untuk dibaca cepat atau di-export.

## Kolom

| Kolom | Sumber |
|---|---|
| Project | `name` + `code` |
| Manager | `manager.name` |
| Schedule | `start_date` – `end_date` |
| Progress | angka % + progress bar |
| Health | dihitung |

## Interaksi

- Klik nama project → Project Detail.
- (Opsional) tombol export ke CSV di header halaman.
