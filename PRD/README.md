# Project Management Dashboard — Spec Package

Dokumentasi ini adalah paket spesifikasi untuk membangun ulang Project Management Dashboard dari nol (bukan Canva App, aplikasi web mandiri). Ditujukan untuk AI coding agent atau developer.

## Struktur Dokumen

| File | Isi |
|---|---|
| `01-overview.md` | Tujuan produk, entitas inti, daftar modul |
| `02-architecture.md` | Stack teknis, alasan pemilihan, setup project |
| `03-database-schema.md` | ERD, tabel, kolom, relasi, enum |
| `04-api-reference.md` | Daftar endpoint REST |
| `05-design-system.md` | Warna, tipografi, komponen visual |
| `features/01-dashboard.md` | Modul Dashboard |
| `features/02-calendar.md` | Modul Calendar |
| `features/03-projects.md` | Modul Projects (list) |
| `features/04-project-detail.md` | Detail project + WBS |
| `features/05-gantt.md` | Modul Gantt |
| `features/06-kanban.md` | Modul Kanban |
| `features/07-planner.md` | Modul Planner |
| `features/08-reports.md` | Modul Reports |
